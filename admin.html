Isi portofolio disimpan sebagai berkas di repositori GitHub Anda. Setiap kali diterbitkan, GitHub Pages akan membangun ulang website.

Token hanya dipakai selama halaman admin ini terbuka. Token tidak ditulis ke berkas website atau penyimpanan browser.

Cara membuat token khusus untuk editor ini
  1. Buka GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Buat token untuk pemilik repositori fadhlanqital dan pilih repositori fadhlanqital.github.io.
  3. Di Repository permissions, beri Contents: Read and write. Biarkan izin lain tetap tidak diberikan.
  4. Buat token, salin, lalu tempel di kolom di atas. Jangan kirim token ke orang lain.
